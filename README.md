## About Me

I'm a Flutter developer focused on building maintainable mobile applications with modern
state-management patterns and clean, layered architectures.

- 📱 Building cross-platform apps with **Flutter** and **Dart**
- 🏗️ Architecting with **Clean Architecture**, **GetX**, **Riverpod**, and **Bloc**
- 🧩 Writing functional error handling with **dartz** (`Either` / `Option`)
- 🔥 Shipping real-time features on **Firebase** — Auth, Firestore, Storage
- 💾 Persisting data locally with **SQLite / sqflite** and **Hive**
- 🌐 Also building backend tooling in **Node.js** using the raw `http` module
- 🎨 Crafting polished **animations**, **transitions**, and reusable **UI components**

I care about code that stays readable and testable long after the first release.
